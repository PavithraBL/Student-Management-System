# Student Management System (Java)

## About the Project
This is a simple console-based Student Management System built using Java. It allows users to manage student details through a menu-driven program.

## Features
- Add a new student
- View all students
- Search for a student by ID
- Delete a student by ID
- Update student details
- Prevent duplicate student IDs
- Validate menu choices

## Technologies Used
- Java
- ArrayList
- Scanner
- Object-Oriented Programming (OOP)

## How to Run
1. Install the Java JDK on your computer.
2. Download or clone this repository.
3. Open a terminal in the folder containing `Student.java`.
4. Compile the program:

   ```bash
   javac Student.java
   ```

5. Run the program:

   ```bash
   java Student
   ```
